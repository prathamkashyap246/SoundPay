SoundPay Jam Lab

Can someone jam a payment made over sound?

Each run sends a real 16-character payment token through a simulated room, with the same modem code the app uses, and decodes it the way the customer's phone would. Pick how the token is sent, put something in the room, and see whether the payment gets through.
